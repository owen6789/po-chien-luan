# Po-Chien Luan Academic Website

This is a static academic website built from the initial CV materials in `assets/CV.pdf`, with the profile image loaded from `assets/profile.jpg`.

## Edit Your Content

Most content lives in [data/site-data.js](data/site-data.js). Update this file when you want to revise:

- name, title, affiliation, location, email, and links
- short bio and research interests
- news items
- selected publications, paper links, code links, project pages, and thumbnails
- the opportunity callout and Google Scholar link

The current profile photo and CV are set in `data/site-data.js` as `assets/profile.jpg` and `assets/CV.pdf`.

## Preview

Open [index.html](index.html) in a browser. Because the site does not require a build step, it also works well on GitHub Pages.

## Publish With GitHub Pages

Push this repository to GitHub, then enable GitHub Pages from the repository settings. Use the `main` branch and the root folder.

## Suggested Material Checklist

- Profile photo
- CV PDF
- Google Scholar, GitHub, LinkedIn, ORCID, lab, and personal links
- 2-3 paragraph biography
- Research interests
- News items with dates
- Publication list with venue, authors, links, summary, and optional thumbnail
